# 迷你世界风格小地图 · 设计终稿（星穹优化模组）

纯客户端 UI。只读 `ClientWorld` / Chunk / BlockState / Player / LivingEntity，零方块/实体/服务端逻辑。

## 管线

```
世界只读 → 采集(ChunkScanner) → 缓存(色块/探索/标记/战斗) → 渲染(小地图/大地图/信息HUD/头顶心)
```

## 硬约束

| 项 | 约定 |
|----|------|
| 标记 | 纯坐标 JSON，创建后坐标不可改（改=删重建） |
| 自己血条 | 只用原版底部 HUD |
| Boss | 末影龙/凋灵只用原版 Boss 栏 |
| 头顶心 | 默认渲染距离 **16 格**（可靠近显示，勿拉大） |
| 小地图实体点 | **不绘制**（仅地形 + 自建标记图标） |

## 快捷键

| 键 | 功能 |
|----|------|
| M | 大地图开/关 |
| B | 当前位置加标记 |
| Z | 按住临时放大小地图 |
| N | 锁北 / 随转向 |
| H | 隐藏/显示全部 HUD |
| U | 标记列表（大地图内） |

## 开发阶段

P0 地形小地图 → P1 信息 HUD → P2 标记 → P3 大地图 → P4 缓存/迷雾 → P5 近距心形血条 → P6 实体点/洞穴/配置
